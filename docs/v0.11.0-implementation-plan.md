# v0.11.0 实施推进计划

日期：2026-11-10。开发分支：`dev/v0.11.0`。设计依据：[升级方案](v0.11.0-upgrade-plan.md)。本计划区分已落地的库改进、尚未接线的宿主能力以及未执行的验收；不把设计目标当作现有 API。

## 1 基线与交付边界

开工库基线为 `32656b6`（`main`），包版本 `0.10.0`、SQLite schema 8。原方案的 `3e337cb` 早于工作流分支整合，不能继续用于判断当前缺口。宿主只读核对 `E:/Repos/MinecraftLLM`，HEAD 为 `1390aac514427e44c91a6d616135d8e8e74a6f0d`；本批不修改另一仓库或部署中的服务。

现状复核：

- 库已经包含 `retainNewestObservedCells` 及删除落盘逻辑。它会真正遗忘观察，不能当作缓存换出。本批保留这个公开兼容接口，后续以成套冷存方案替换宿主调用，不能只删钩子或放大容量常量。
- `planRoute` 的旧 `auto` 仅在指定 `pathId` 时优先历史；不带 `pathId` 原本就走体素搜索。本批统一为 `auto → search`，指定历史路线用 `source: 'history'`。
- 库的 `observe` 和普通执行器不会自己生成 Fragment；宿主 `TraversalRecorder → SharedSpatialSession.recordWalkCorridor` 才是普通移动的主要旧写入链。只删库 Fragment 类型无法使宿主停止增长。
- 宿主已有最小堆三维 A*、Coordinator、真实身体执行与合法感知。库已有碰撞/支撑几何、陆地转换验证、到访位、单 Worker、manual 工作集及 pin/dirty 保护，应复用。
- 默认 `openSpatialSession` 仍恢复历史域；manual 模式只改变体素载入方式，目录仍全量驻留。地图、目录、单批保存和总库额度尚未拆分。

本次落地的是 **M0 与 M1/M2/M4 的首批库基础改进**，不是 v0.11.0 发布完成。包版本、schema 和已有数据库保持原状。用户开工前的设计文档修改、未跟踪工作树和发布文件不属于本次提交。

## 3 搜索迁入契约

搜索消费 `VoxelMap`、明确世界/维度/会话、实际脚位、目标/到达条件、碰撞规则与委托预算。输出只是一条临时几何候选及事实缺口，不是 `ARRIVED`、执行授权或当前全程 `OPEN`。宿主配置、Minecraft 客户端读取、危险偏好、自动施工和救援策略不随算法迁入。

首批能力限定 walk/step/drop，保持小数支撑高度及实际起点。精确目标不能静默改成格心或附近高度；near 目标按原三维范围判断。记忆几何读取保留实际时间、会话、状态完整性和来源，禁止构造可被外部当作当前证据的 FRESH 副本。未知、未驻留、缺属性、预算不足分别报告；冷读接入前明确报缺口。

搜索限制节点、边检查、输出大小和时间；异步切片真正让出事件循环，路线重建采用线性收集。启发式用已证明的下界，与相同图和边代价的零启发式参考比较。单次碰撞提供器成本仍属于宿主提供器契约，需在真实负载中计入耗时。

当前公开入口为 `searchLandRoute` / `searchLandRouteAsync`（根入口和 `navigation` 子路径），支持 `arrival: exact | near`、`evidenceMode: current | remembered`。`maxSurfaceReads` / `stats.surfaceReads` 专指支撑面枚举及该阶段的邻格读取，不冒充所有几何读取量；转换评估另受 `geometryLimits`、边数量与调用期限约束。异步版本在发布结果前核对依赖页驻留代次；保存但未驻留的页只报告 `unavailableSections`，不会隐式加载。

`planRoute` 原有 `RouteSearchSource`/walk 执行协议保持显式边界；新三维候选不强塞为同高 walk，也不改能力表谎称已完成身体支持。B5 完成接线后，才能删除宿主重复搜索实现。

## 9 B5.1 记录：走廊扩张与当前证据候选前缀（2026-11-10，已完成定向验证）

### 18.1 规模探针边界补充

- `voxelBatchMaxBytes` 是软上限：单个超大 Section 仍会被包含以保证前进；调用方不能把它当作硬性单 Section 上限。
- `snapshotLimits.maxBytes` 是整库已提交集合上限（worker 校验），不是单批上限。4M 实测 payload 505.6–530.1MiB；探针默认 3GiB，宿主默认已调整为 1024MiB 并保留单批 16MiB。
- 批次上限超过整库上限时，库在 open 边界拒绝，不再静默 `Math.min` 夹取（`voxelBatchMaxBytes` 校验）。
- 总库容量不足时可能在已提交若干批次后由 worker 拒绝后续批次；已提交批次保持可读，剩余 dirty 如实保留，不整体回滚。
