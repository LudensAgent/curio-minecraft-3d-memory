## 1. 库事实存储契约（A 提供）

事实记录沿用 `src/facts/types.ts`，并补充容器 gone 状态：

```ts
interface ContainerAnchorFact {
  // existing fields...
  gone: boolean;
  goneAt?: number;
  goneSource?: FactProvenance;
}

interface FactStore {
  // Synchronous memory authority. Writes are visible to reads immediately.
  upsertPlace(fact: PlaceFact): FactWriteResult<PlaceFact>;
  upsertResource(fact: ResourceAnchorFact): FactWriteResult<ResourceAnchorFact>;
  upsertContainer(fact: ContainerAnchorFact): FactWriteResult<ContainerAnchorFact>;
  markPlaceGone(id: string, evidence: FactGoneEvidence): FactWriteResult<PlaceFact>;
  revokeResource(id: string, evidence: FactGoneEvidence): FactWriteResult<ResourceAnchorFact>;
  markContainerGone(id: string, evidence: FactGoneEvidence): FactWriteResult<ContainerAnchorFact>;
  updateResourceSource(id: string, update: ResourceSourceUpdate): FactWriteResult<ResourceAnchorFact>;

  places(query?: FactQuery): FactPage<PlaceFact>;
  resources(query?: ResourceFactQuery): FactPage<ResourceAnchorFact>;
  containers(query?: FactQuery): FactPage<ContainerAnchorFact>;

  // Persistence lifecycle. In-memory acceptance is not a save confirmation.
  readonly revision: number;
  readonly confirmedRevision: number;
  checkpointSnapshot(): FactCheckpointSnapshot;
  installSnapshot(snapshot: FactCheckpointSnapshot): void;
  confirmRevision(revision: number): void;
  hasPendingChanges(): boolean;
}
```

Rules:

- Sync writes/queries are the hot-path authority; SQLite commit is explicit and asynchronous.
- ACK confirms only the captured revision; a late ACK never clears newer facts.
- Restart installs the committed snapshot with original `observedAt`, stable ids and gone/revoked state.
- Deletion is not exposed as physical delete for facts; gone/revoked is retained state.
- Migration version/target is recorded in the same persistence authority. A missing new-domain record must not fall back to topology/fragments/JSON.
- Container contents remain host-led; only the anchor and optional ledger ref are stored.

## 2. 宿主事实适配契约（B 提供）

B 新增一个窄宿主端口，供 `SpatialSemanticStore`/travel store 和整合者使用：

```ts
interface HostFactsPort {
  upsertPlace(place: PlaceFact): FactWriteResult<PlaceFact>;
  upsertResource(resource: ResourceAnchorFact): FactWriteResult<ResourceAnchorFact>;
  upsertContainer(container: ContainerAnchorFact): FactWriteResult<ContainerAnchorFact>;
  markPlaceGone(id: string, evidence: FactGoneEvidence): FactWriteResult<PlaceFact>;
  revokeResource(id: string, evidence: FactGoneEvidence): FactWriteResult<ResourceAnchorFact>;
  markContainerGone(id: string, evidence: FactGoneEvidence): FactWriteResult<ContainerAnchorFact>;
  updateResourceSource(id: string, update: ResourceSourceUpdate): FactWriteResult<ResourceAnchorFact>;
  places(query?: FactQuery): FactPage<PlaceFact>;
  resources(query?: ResourceFactQuery): FactPage<ResourceAnchorFact>;
  containers(query?: FactQuery): FactPage<ContainerAnchorFact>;
}

function convertHostSemanticNode(node: HostSemanticNode): HostFactConversion;
```

Host conversion MUST classify by `metadata.curio.type` before `node.tag`/`kind`:

| `metadata.curio.type` | fact |
|---|---|
| `container`, `chest` | `ContainerAnchorFact` + stable externalRef/ledgerRef |
| `furnace` | `ContainerAnchorFact` with furnace externalRef/ledgerRef (or explicit place only if ledger cannot be associated) |
| `farm` | `PlaceFact` (`station`/`place`) with exact or area location; never a resource |
| `resource` | `ResourceAnchorFact`, exact cell only |
| `base`, `death`, `portal`, `station`, `hazard` | matching `PlaceFact` |
| `gone` | matching fact with gone state retained; container gone supported |
| unknown/missing type | explicit conversion gap, not silently dropped |

Layering:

- Host `metadata.curio` is authoritative for role; `tag:"resource"` alone is not.
- Preserve stable id, original `observedAt`, dim/world, business metadata that has a fact field, and container ledger association.
- Area/region farm/station remains a `PlaceFact` area; never promoted to an exact resource or container cell.
- Container gone must migrate as gone, not `unknown`.

B owns the host conversion and semantic-store/travel-store refactor. Integrator wires `HostFactsPort` into `SharedSpatialSession`/`main.ts`.

## 3. 导航迁移契约（C 提供）

- All production navigation decisions use voxel A* via `navigate_to`/`advance`; no old `historyRoute`, `fragment`, `walk_path` routeId or `travel_to via:"history"|{fragment}` decision path.
- `travel_to` may remain only as a thin explicit direct/pathfinder fallback if still used; its default must not prefer old routes. If a caller no longer needs it, migrate to `navigate_to`/`advance`.
- Code skills, recovery, activity, stance, prompt and tool catalog must advertise the new names only. Old names must not be silently accepted as a different semantic.
- Cancellation, deadline, target kind, exact/cell arrival, partial effects and session continuation retain existing contracts.
- C must add tests that old route preferences are not executed and that the new wrappers reach the same targets.

1. A and B merge first (fact contract/persistence + host conversion), while C works on navigation callers.
2. Integrator wires facts into `SharedSpatialSession` and `main.ts`, updates package artifact, and runs combined tests.
3. C's navigation changes merge after the shared session/facts wiring is stable.
