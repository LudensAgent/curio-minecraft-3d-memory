# Curio 体素地图查看器

导入本地 SQLite，在全窗口三维地图中查看已保存的体素、资源点、容器锚点、传送门端点和其他记录点。

## 启动

使用 Node.js 22.12+，浏览器推荐当前版本的 Chrome / Edge。

```powershell
cd D:\Repos\curio-minecraft-3d-memory\demo\voxel-atlas
npm install
npm run dev
```

打开终端显示的地址，默认 `http://127.0.0.1:5174`。这是独立 demo，不需要修改主库的依赖或启动游戏。

## 使用

1. 选择或拖入 `.sqlite` 文件。左上角的“选区”会自动展开，供你选择世界与维度。
2. 在区块图上框选范围，或输入坐标和 Y 高度后点击“加载选区”。加载完成后选区窗口自动收起。
3. 左上角的“记录与图层”列出本区的资源、容器、传送门和地点，并提供图层开关。
4. 点击体素或记录，左下角的“观测详情”会显示坐标、来源与观测时间。也可单独展开它查看选区边界和统计。再次点击窗口按钮或按 Esc 可收起。

SQLite 以数据流复制到浏览器本地存储，不上传服务器，也不改原文件。导入需要复制整个文件，但不会用一个 JavaScript 缓冲区装下整库；只有选区内的体素会被解码。单次最多 512 个 Section、64 MiB 的序列化 Section 数据、200,000 个已观测格，超出时会要求缩小范围。

## 三维 A* 红石寻路

加载选区后，打开右上角的“红石寻路”，点击“点选 A”。窗口会收起，方便在地图上依次选择 A、B，选完后自动展开。实心体素取其上方脚格，空气取本格。也可以直接输入脚格坐标，半砖等表面可手动调整 Y。

点击“开始寻路”后，独立 Worker 运行库内真实 `searchLandRoute`。暗红色红石粉按顺序回放实际展开的搜索节点，亮红色红石连接最终路径。支持暂停、拖动进度、直接查看完整路径；半透明身体仅示意沿路线移动，动画速度不代表计算耗时，也不会控制游戏。

默认“历史几何模拟”假定保存的方块没有变化，保留原始证据，未知格仍为未知。“当前证据检查”要求当前有效证据，离线恢复的记录通常会返回过期。两种模式都不代表当前可执行或已经到达。

搜索只使用已加载选区，按 Minecraft Java 1.20.1 碰撞形状检查行走、上阶和有界下落，不执行挖掘、放置、飞行或传送。缺失属性、不支持的几何、液体和未知区域会保留为缺口。搜索有节点、读取量和时间预算；回放最多保留前 6,000 个实际展开节点，超出会显示提示。取消、换区或更换文件会终止计算并清理旧路线，不修改 SQLite。

## 数据含义

- 空气必须有实际观测，未知位置保持空缺；显示的是保存的历史，不代表当前世界或已经验证的通行性。
- 容器显示位置、身份和账本引用，空间数据库没有库存内容。
- 传送门只显示已保存的端点，不推断连接或返程。
- 区域型记录保留范围，不当成精确点；已消失、已撤销记录可以单独显示。
- 不加载旧路线图、旧矿道或历史路径。
- 请导入已关闭的数据库或一致性备份；单独选择 `.sqlite` 不会读取旁边 `-wal` 中尚未合并的事务。
- “清除文件”会移除本查看器的浏览器本地副本。浏览器存储配额仍然适用。

## 构建

```powershell
npm run build
npm run preview
```

另行部署静态文件时，需要 HTTPS 或 localhost，以及 `Cross-Origin-Opener-Policy: same-origin` 和 `Cross-Origin-Embedder-Policy: require-corp` 响应头。不能直接双击 `index.html` 以 `file://` 打开。

体素解码直接使用仓库实现，因此请保留项目在当前仓库中的目录关系。运行时资源均在本地提供，不依赖外部 CDN。
