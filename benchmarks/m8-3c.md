# M8.3 H6 checkpoint before/after (L-M8-3c)

Domain-separated checkpoint: only domains whose in-memory revision leads the
confirmed revision are sent, and a committed ledger is carried forward as a
delta instead of a full snapshot. This file records the before/after probe for
that change.

> **Scope.** Synthetic fixtures, a real SQLite worker, and `mkdtemp` databases
> only. No Minecraft server, no mineflayer, no real body. These numbers are not
> acceptance evidence for gameplay; they only compare the same probe on two
> worktrees of the same machine.

comparisons, not absolute thresholds.

## Scale (identical in every run)

- history/topology: 20 000 nodes, 20 000 edges, 1 000 fragments, 20 000
  traversals (the `benchmarks/fixtures.ts` topology fixture).
- ledger: 20 000 placed blocks + 20 000 chunk visits.
- database at the end of the run: 64 430 288 B (~61.4 MiB).
- The ledger snapshot that the before tree re-serializes every checkpoint is
  5 804 157 B (~5.5 MiB); a 20-row delta (10 placed + 10 visits) is 3 145 B.
- First baseline checkpoint runs outside the measured window. Each measured
  round changes the named domain and then times only `checkpoint()`, 5 rounds
  per scenario, p95 over those rounds.

## Steady-state checkpoints (p95 ms, worse of two runs)

| scenario | before p95 | after p95 | after/before |
|---|---:|---:|---:|
| no-change (all domains clean) | 733.13 | 0.61 | ~1/1200 |
| ledger-only (+10 placed, +10 visits per round) | 1198.29 | 43.17 | ~1/27.8 |
| topology-only (+1 node update per round) | 1072.56 | 298.99 | ~1/3.6 |

Per-run detail (median / p95 ms):

| run | no-change | ledger-only | topology-only |
|---|---:|---:|---:|
| before #1 | 731.09 / 733.13 | 1194.75 / 1198.29 | 1068.74 / 1072.56 |
| before #2 | 699.96 / 701.07 | 845.42 / 932.96 | 999.62 / 1001.54 |
| after #1 | 0.28 / 0.36 | 41.65 / 43.17 | 296.66 / 297.96 |
| after #2 | 0.44 / 0.61 | 39.27 / 41.73 | 294.96 / 298.99 |

What each row shows:

- **no-change**: before re-serializes and rewrites all four domains every time;
  after writes only the checkpoint row. This is the upper bound of the change,
  not a promise about mixed workloads.
- **ledger-only**: the intended H6 win. History/topology are omitted entirely
  and the ledger sends a ~3 KiB delta instead of a ~5.5 MiB snapshot. The
  remaining 40 ms is the worker's post-write full-set re-read for the capacity
  and byte bounds (the delta is never the authority for what stays on disk).
- **topology-only**: history stays omitted, but the dirty topology domain is
  still a full replacement, so this row only removes the history and ledger
  work. It is included so the doc does not imply per-row topology deltas exist.

## What changed behind these numbers

- `historyMode`/`topologyMode`: `full` only when that store's revision leads its
  confirmed revision; otherwise `none`, which the worker treats as "keep the
  committed rows and the previous checkpoint's topology extras untouched".
- `ledgerMode`: `full` for the first save in a session, then `delta` (upserts,
  removals, and appended portal crossings captured since the last confirmed
  checkpoint). Omission is never a deletion.
- The worker reads the committed full set back inside the transaction for a
  delta and enforces the same capacity/byte limits as a fresh open; it also
  reports the committed ledger count/bytes in the ACK.
- ACKs clear only the captured pending tokens, so a key re-dirtied after capture
  is re-sent rather than overwritten.

## Probe script

Copy to `/tmp/m8-3c-bench.mts` (extension matters: top-level `await` needs ESM).

```ts
import { mkdtempSync, rmSync, statSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { pathToFileURL } from 'node:url';

const root = process.argv[2];
if (!root) throw new Error('usage: bench <worktree-root>');

const { openSpatialSession } = await import(pathToFileURL(join(root, 'dist/storage/sqlite/index.js')).href);
const fixtures = await import(pathToFileURL(join(root, 'benchmarks/fixtures.ts')).href);
const { buildTopologyFixture, topologyPlan, WORLD } = fixtures;

const NODES = 20_000;
const EDGES = 20_000;
const FRAGMENTS = 1000;
const SPINE = 1024;
const PLACED = 20_000;
const VISITS = 20_000;
const ROUNDS = 5;

const fixture = buildTopologyFixture(topologyPlan(NODES, EDGES, SPINE, FRAGMENTS));

function dbBytes(path) {
  const size = (p) => {
    try {
      return statSync(p).size;
    } catch {
      return 0;
    }
  };
  return size(path) + size(`${path}-wal`) + size(`${path}-shm`);
}

function percentile(values, q) {
  const sorted = [...values].sort((a, b) => a - b);
  return sorted[Math.min(sorted.length - 1, Math.floor(q * (sorted.length - 1)))];
}

async function scenario(name, mutate) {
  const dir = mkdtempSync(join(tmpdir(), 'm83c-bench-'));
  const databasePath = join(dir, 'bench.db');
  const session = await openSpatialSession({ databasePath, worldId: WORLD, fragmentOptions: { maxTraversals: EDGES } });
  try {
    session.history.restoreSnapshot({ worldId: WORLD, fragments: fixture.fragments, traversals: fixture.traversals });
    session.topology.restoreSnapshot(fixture.topologySnapshot);
    for (let i = 0; i < PLACED; i += 1) session.ledger.putPlaced('overworld', { x: i % 200, y: 64, z: Math.floor(i / 200) }, 'minecraft:stone');
    for (let i = 0; i < VISITS; i += 1) session.ledger.visitChunk('overworld', i % 500, Math.floor(i / 500));
    await session.checkpoint();

    const times = [];
    let rssPeak = process.memoryUsage().rss;
    const sampler = setInterval(() => { rssPeak = Math.max(rssPeak, process.memoryUsage().rss); }, 5);
    try {
      for (let round = 0; round < ROUNDS; round += 1) {
        mutate(session, round);
        const start = performance.now();
        await session.checkpoint();
        times.push(performance.now() - start);
      }
    } finally {
      clearInterval(sampler);
    }
    return {
      scenario: name,
      medianMs: Number(percentile(times, 0.5).toFixed(2)),
      p95Ms: Number(percentile(times, 0.95).toFixed(2)),
      minMs: Number(Math.min(...times).toFixed(2)),
      maxMs: Number(Math.max(...times).toFixed(2)),
      rounds: times.length,
      dbBytes: dbBytes(databasePath),
      rssPeakMiB: Number((rssPeak / (1024 * 1024)).toFixed(1)),
    };
  } finally {
    await session.close();
    rmSync(dir, { recursive: true, force: true, maxRetries: 10, retryDelay: 50 });
  }
}

const results = [];
results.push(await scenario('no-change (all domains clean)', () => {}));
results.push(await scenario('ledger-only (+10 placed, +10 visits per round)', (session, round) => {
  for (let i = 0; i < 10; i += 1) {
    session.ledger.putPlaced('overworld', { x: 900 + (round % 50), y: 70, z: 900 + i }, 'minecraft:cobblestone');
    session.ledger.visitChunk('overworld', 900 + (round % 50), 900 + i);
  }
}));
results.push(await scenario('topology-only (+1 node update per round)', (session, round) => {
  const node = fixture.topologySnapshot.nodes[round];
  session.topology.updateNode(node.id, { label: `mut-${round}` });
}));

for (const result of results) {
  console.log(`${result.scenario}\tmedian=${result.medianMs}ms\tp95=${result.p95Ms}ms\tmin=${result.minMs}\tmax=${result.maxMs}\trssPeak=${result.rssPeakMiB}MiB\tdb=${result.dbBytes}B`);
}
```
